# Global Exam Pager

Script JavaScript a coller dans la console du navigateur sur une page Global Exam.

## Ce que fait le script

- clique sur `Suivant`, `Terminer`, `Next` ou `Continuer`
- attend entre les clics
- clique sur `Passer` ou `Skip` quand le bouton apparait
- recommence en boucle

## Utilisation

1. Ouvrir la page Global Exam.
2. Ouvrir la console (`F12` ou `Ctrl+Shift+I`).
3. Si le collage est bloque, taper `allow pasting`.
4. Coller le contenu de `Script.js`.
5. Valider avec `Entree`.

Le script demarre automatiquement.

## Commandes

- `geStart()` ou `gs()` : demarrer
- `geStop()` ou `gx()` : arreter
- `geStatus()` ou `gi()` : voir l'etat
- `geHelp()` ou `gh()` : afficher l'aide
- `geDelay(30)` ou `gd(30)` : changer le delai principal

## Fichier

- `Script.js`
